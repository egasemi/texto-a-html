# Texto a HTML

Una aplicación web mínima para pegar texto desde el portapapeles, previsualizarlo y descargarlo como un archivo `.html` autocontenido.

## Usar la app

Abrí **[egasemi.github.io/texto-a-html](https://egasemi.github.io/texto-a-html/)**.

1. Pegá el texto con el botón o escribilo en el editor.
2. Elegí el título de la pestaña y el nombre del archivo.
3. Revisá la vista previa y presioná **Descargar HTML**.

Todo el procesamiento ocurre en el navegador: el contenido no se envía a ningún servidor.

## Desarrollo local

No requiere instalación ni proceso de compilación. Podés abrir `index.html` directamente o servir la carpeta con cualquier servidor HTTP estático.
